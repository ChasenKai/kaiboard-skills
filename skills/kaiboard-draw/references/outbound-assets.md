> 来源：2026-09-21 ~ 22 从零做出 README 全部 6 张配图的过程沉淀。
> **下次要做对外图，照这份走；里面的坑都是实测踩出来的。**

## 一、三种取图方式（先选对）

| 要什么 | 怎么做 | 说明 |
|---|---|---|
| **只要画板内容** | MCP `getScreenshot(boardId)` | **不需要那张板在前台**，给 id 就行 |
| **要整个界面**（含左侧树 / 顶栏）| `internal/tools/capture_ui.py <name>` | Win32 PrintWindow，自动裁掉浏览器 chrome |
| **一张板出多张图** | 一次整板截图 → 按**真实坐标**裁 | 见下"坐标纪律" |

## 二、🔴 坐标纪律（本项最贵的教训）

**症状**：标的东西老是偏（Kai 打趣「你眼斜」）。

**根因**：在用**眼睛估**坐标，而不是取真值。

**规则**：
1. **画布内坐标 → 一律从板 API 取真值**（`getBoard` 返回每个元素的 x/y/width/height），**禁止目测**
2. 截图 = 所有元素的**包围盒** → 所以 board→screen 是**线性映射**：`s = 截图宽 / 包围盒宽`
   → 裁切框写 `(x*s, y*s, (x+w)*s, (y+h)*s)` 即可，一次就对
3. **量尺先确认**：别把 1500 宽的预览图当 1080 用（我在这上面连错 4 次）
4. **UI 元素（顶栏、侧栏、工具条）不在板数据里** → **不要自己估**，请 Kai 标或直接问他框哪一段

**反面实证**：hero 的 Agent 光标被我估到 **y=1338**（画布外 80px）❌；
改用 API 读到「白板」框在 **x=852 y=846** → 一次就对 ✅

## 三、🔑 截「画布上的 Agent 协作光标」

**机制**（`app/src/agent/agentBridge.ts`）：KaiBoard 把 Agent 注册成**虚拟协作者**
（`kaiboard-agent`，用户名 `Agent`，色 `#22c55e`）走 Excalidraw **原生 collaborator 通道** →
写入后**同时出现三处**：① 协作光标（带「Agent」名牌）② 刚写入元素的半透明描边 ③ 协作者头像。

**成败关键**：`AGENT_PRESENCE_MS = 20000` —— **只亮 20 秒**。

**正确做法**：
1. 确认板已打开（`/state` 的 `waiterBoards` 会显示当前页面所连的板）
2. **只 `patchElement` 一个可见元素**（**同文本**即可 —— 会换 `versionNonce` → 被判定"Agent 刚写过"）
   → **不污染画板**、不影响内容 ✅
3. **20 秒内**截图
4. ⚠️ **写入位置必须在视口内** —— 写到视口外，光标出现在屏幕外；而自动滚动要 **20 秒后**才触发（那时已消失）

> 想拿到**更稳**的结果：让 Kai 看着截（他提的协作方案）—— 我 patch 他截，不用猜时机。

## 五、格式规范
见 `internal/assets/README.md` → **RGB 去 alpha / 必须嵌 sRGB / 2x 尺寸 / `optimize+compress_level=9`**。
一句话：**界面图不要留 alpha**（全不透明的 RGBA 白占 36% 体积）。

## 六、目录约定（**对外引用只走 `app/assets/`**）

```
internal/assets/v2/shots/
  final/     ← 正式成品（只放交付物；README 用的图都在这）
  _process/  ← 过程产物（gitignored，可随时清）
  raw/       ← 中间位图（gitignored）
app/assets/  ← README 实际引用的图（对外可见，勿引 internal）
```

## 七、⚠️ 三条「别做」

1. **别在整图上打编号点**（需精确坐标、必压内容）→ 要么「整图 + 右侧放大块」，要么**请 Kai 标**
   （Kai 自己标 3 个点比我调 4 版都快 ✅）
2. **别把说明文字写进图里** → **图只放标记，说明写文档** —— 这样同一张图能多渠道复用
   （Kai 定的做法，已写进交接包 §10.2）
3. **别自己硬画插画**（我画的猫被评为"不够展示级"）→ **用社区素材库**
   （见 `references/library-recipes.md`）
