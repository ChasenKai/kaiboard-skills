# 画图方法论（广义）— 借鉴来源与合成

> 本 skill 不止画框架图。草图、手绘、标注插画、线框、概念图、思维导图、教学图解、视觉笔记都能画。
> 本文把多个公开 Excalidraw 画图 skill / 教程的成熟方法论**学过来并引用**，作为本 skill 的「美学与构图总纲」。
> 后续任何画图任务：先对照本文选技法，再落地到 `gen_excalidraw.py` 或 Mode A 共绘。
>
> 心法：**先想清「这张图属于哪类、线会不会穿框、要草感还是技术感」，再决定布局与技法，而不是画完再救。**

## 一、风格档位：草图 ↔ 技术图（总开关）

用 `roughness` / `sloppiness` 控制手绘强度，这是「草图/手绘」和「框架图」都能画的关键：

- **草图 / 手绘 / 概念图** → 高 `roughness`（Cartoonist / Artist），**故意留粗糙边**更「有人味、可亲近」（toxigon：技术图收干净，草图留点乱，反而比 corporate PPT 更可信）。
- **技术图 / 框架图 / 线框** → 低 `roughness`（Architect），干净、对齐、精确。
- 本 skill 默认 `roughness≈0.8`（契合 KaiBoard 手绘主题）；草图任务显式调到 **1.5–2.5**，技术图降到 **0.6–1.0**。

## 二、通用视觉技法（10 条精华，跨图型通用）

> **任何画图任务生成前先对照本节。** 参考 `robonuggets/excalidraw-skill`（10 visual techniques + 截图自纠），`scripts/gen_excalidraw.py` 已内置其中大部分。

1. **hachure 手绘填充**，别实底（实底=死板/业余头号原因）。
2. **语义配色用 role**，不用手写色；红只给 danger。
3. **字体层级**：标题 / 区块 / 正文 / 注释（`TITLE_SIZE/BODY_SIZE/NOTE_SIZE`）。
4. **混合形状**：判断用菱形、参与者用椭圆，别清一色矩形。
5. **线型语义**：实线=同步、虚线=异步/可选。
6. **留白宁大勿小**（挤=乱的二号原因）。
7. **中文不溢出**（自动折行 + 撑框）。
+ 本文补充纪律（toxigon / ai-bar）：
8. **配色克制**：2–3 主色 + 黑字，别彩虹爆炸。
9. **描边匹配箭头**：粗线配大箭头头，细线小箭头头，否则「不平衡 / 箭头像针尖」。
10. **缩到 50% 自检构图**：zoom out 看整体——谁太大、线歪、挤成一团（数字版的「后退看画」）。
11. **组件复用**：常用组合（图标+名）Group 后复制，别每次重画（ai-bar）。

## 三、连接与箭头路由（技术图 / 流程图核心，防「线乱穿框」）

- **绑定**：箭头 `start/endBinding` 到框；移动框箭头跟随（Excalidraw 会自动让绑定箭头绕开别的框——你手动挪完后看到的「曲折躲方框」线就是它在绕障）。
- **精准停靠 `fixedPoint`**：决定从框的哪条边出/入——
  - 纵向流：底↔顶 `[0.5,1] → [0.5,0]`
  - 横向流：左↔右 `[0,0.5] → [1,0.5]`
  - 停靠边对了，线基本不穿框。
- **同边多箭头分散 `stagger`**：从一个框扇出多根，用 `focus` 或 20%/50%/80% 散布在边宽上，互不重叠。
- **路由模式选型**（neversight）：
  - 同列/同行直落 → **直行**
  - 「下→横→下」 → **L 形**
  - 回环绕到上方/下方 → **U 形 bypass**
  - 要优雅弧过 → **曲线**（waypoint + `roundness`）
  - 必须横穿 → **肘线 Z 形**
  - **铁律：箭头要穿无关框 → 加 waypoint 绕开，绝不接受交叉。**
- **防穿框布局**（excalidraw-3）：回环 `A→B→C→A` 用**三角**；4 节点环形用**菱形 / 2×2**；多节点顺序+回环拆成「去程上排、回程下排」。
- **背景区完整包裹**：外部箭头连到外层**容器框**（容器绑定）；背景矩形必须完全罩住所有子元素。
- **收尾前走查**（acking-you）：逐箭头 mental trace——不穿无关框、标签不压框、背景罩住子元素。

## 四、标注与注释（草图 / 插画 / 概念图核心）

- 文字框标注、callout、代码块（把代码贴进文本框，手绘字体像草稿本）、引线/指针指向被标注部位。
- 这是「手绘插画」「概念图」「教学图解」区别于纯框架图的关键技法——框架图讲「结构」，标注插画讲「这里有什么、注意什么」。

## 五、构图与留白（通用）

- **指宽间距**（toxigon）：元素间至少留一指宽。
- **对齐**：同层节点对齐到列/行。
- **分组**：相关节点用背景区/容器烘托（`accent` 角色），不抢主体。
- **组件复用**：常用组合 Group 后复制（ai-bar）。

## 六、双轨自检闭环 · 持续学习 Loop（通用）

落板不是终点。**每画完一张图，必须跑一轮自检—修正 Loop**，否则 Agent「看不见自己画的图」会反复犯同样的错（一张稍复杂的图，程序化自检常能一次揪出十几处箭头穿框，肉眼几乎发现不了）。自检拆成两条轨道，互为兜底：

### 通道 A · 程序化自检（确定性，不依赖看图）
- 工具：`geometry_check.py <diag.json>`（裸数组 / `.excalidraw` 都认；退出码 0=PASS / 1=FAIL）。
- 它确定性地查 4 类缺陷（肉眼最难发现的后两种）：
  1. **重复元素 id**（渲染错乱）
  2. **箭头悬空绑定**（引用了不存在的 elementId）
  3. **矩形部分重叠**（非分组的疑似穿叠）
  4. **箭头穿无关内容框**（neversight 铁律「绝不接受交叉箭头」——最致命，肉眼几乎看不见）
- 用法：生成后跑一遍 → **FAIL 就修**（`patchElement` / 改 `gen_excalidraw` 路由助手重生成）→ 再跑 → 直到 PASS。这是 Loop 的主干，因为几何关系不随「模型能不能看图」而改变。
- ⚠️ **通道 A 已知盲区**：
  - **不查「箭头穿箭头」**——每条箭头各自不穿矩形框就 PASS，但多条跨区箭头斜着走会织成视觉网，0 缺陷但极乱。
  - **不查「标签位置」**——可能与框/其它标签重叠。
  - **不查「构图/留白」**——挤不挤由人或多模态眼检。
  - **修法（生成器端）**：跨 zone 箭头**强制正交绕行**（默认 `use_straight = (zone_idx_of(frm) == zone_idx_of(to))`），不靠 `straight_crosses` 退路；同区才允许斜线。

### 通道 B · 截图肉眼复核（给人 / 多模态模型看）
- `getScreenshot` 回看：标签溢出/压框、构图是否挤、整体观感。截图给人复核（或交给支持图像输入的模型二遍眼检）。
- 注意：当前部分模型**不支持把截图读回给自己看**——此时通道 B 只服务于人，通道 A 才是 Agent 自身的修正依据。不要让「Agent 看图」成为 Loop 的唯一依赖。

### Loop 主干（落板后必跑）
```
生成元素 → geometry_check → 若 FAIL：修路由/绑定/重叠 → 再 check → 直到 PASS
         → getScreenshot 给人看 → 人指出问题 / 自己二次眼检 → 再修 → 再 check
```
- **画布是资产，对话是草稿区。** 凡是结构性问题，优先在生成器（`gen_excalidraw.py` 的 `dock_arrow` / `route_pattern` / `style_tier`）里根治，而不是靠 `patchElement` 打补丁。

### 持续学习（站着巨人肩膀的反哺）
- 每轮 Loop 发现的**反复出现的缺陷模式**（如「跨列斜箭头必穿中间框」「同排水平箭头穿过中间框」），要立刻反哺：
  - 路由助手加规则（如本 skill 的 `orthogonal_route` 走分区 gutter 绕开、同排被挡则拱过）；
  - 或补进本方法论 §三（连接与箭头路由）的纪律。
- 让下一次画图**在生成阶段就不犯**，而不是每次都靠 Loop 兜底救。这才是「持续学习、自我修正」的闭环。

## 七、图类型 → 技法映射（让 AI 知道「画什么用哪套」）

| 图类型 | 主用技法 | 风格档 |
|---|---|---|
| 草图 / 手绘 / 概念图 | 二(通用)+四(标注)+五(构图) | 草图档（高 roughness） |
| 标注插画 / 教学图解 | 四(标注)+二+五 | 中–高 roughness |
| 流程图 / 决策树 | 二+三(路由)+六 | 技术档 |
| 架构图 / 框架图 | 二+三+(C4 分层)+六 | 技术档 |
| 线框 / UI 原型 | 一(低保真示意)+四(标注)+二 | 草图档（信号「还是草稿」） |
| 思维导图 / 头脑风暴 | 二+五(放射)+一 | 草图档 |
| 视觉笔记 | 二+四+五 | 中 roughness |

## 八、落地代码助手（`gen_excalidraw.py` 已加）

- `dock_arrow(frm, to, fp_from=(0.5,1), fp_to=(0.5,0), ...)`：`fixedPoint` 精准停靠，避免穿框。
- `stagger(items, ratios=None)`：同边多箭头 `focus` 分散（默认 20/50/80%）。
- `route_pattern(frm, to, mode='straight', ...)`：直行/L/U/曲线/肘线 + 必要 waypoint 绕行。
- `style_tier(tier='technical')`：返回 roughness/描边预设（sketch 高、technical 低）。

> 技法落地对照：§二 的 10 条通用技法中，**hachure 填充 / 语义配色 role / 字体层级 / 绑定箭头 / 中文不溢出** 已内建进 `build()`，无需手写；其余（混合形状、线型语义、分组着色、留白）通过 spec 字段或上述助手函数控制。
